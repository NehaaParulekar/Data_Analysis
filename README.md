# Data Analysis & Statistical Modeling Case Studies

Welcome to this curated collection of data analysis projects. This repository bridges theoretical statistical concepts with real-world business applications, serving as a comprehensive resource for advanced analytics, predictive modeling, and hypothesis testing. 

These case studies demonstrate the end-to-end analytical process, from exploratory data analysis and data wrangling to complex statistical validation and machine learning deployment.

## 📂 Project Directory

* **[Aerofit Customer Profiling & Probability](./Aerofit_probability_and-statistical_analysis)**
  * **Focus:** Descriptive Statistics, Marginal & Conditional Probability.
  * **Description:** A detailed behavioral and demographic profiling of fitness equipment consumers to identify purchasing probabilities and optimize targeted marketing strategies.

* **[Delivery Logistics & Demand Analysis](./Delivery_Demand_analysis)**
  * **Focus:** Route Optimization, Outlier Treatment (IQR), Feature Engineering.
  * **Description:** An evaluation of shipment movement data to identify operational bottlenecks, compare actual delivery performances against routing estimations, and optimize supply chain efficiency.

* **[Jamboree Graduate Admission Prediction](./Jamboree-Admission-Prediction)**
  * **Focus:** Linear, Ridge, and Lasso Regression.
  * **Description:** A predictive modeling framework designed to estimate graduate admission probabilities based on academic profiles, complete with rigorous validation of linear regression assumptions (Multicollinearity, Homoscedasticity).

* **[LoanTap Credit Risk Optimization](./LoanTap-Credit-Risk)**
  * **Focus:** Logistic Regression, Class Imbalance, Risk Analytics.
  * **Description:** An automated underwriting model that predicts personal loan default risk, utilizing precision-recall optimization to minimize non-performing assets (NPAs).

* **[Netflix Content Strategy Analysis](./Netflix-Content-Strategy)**
  * **Focus:** Exploratory Data Analysis (EDA), Data Visualization, Strategic Planning.
  * **Description:** An in-depth analysis of streaming catalogue trends, evaluating content formats, regional production, and optimal release timing to drive global expansion strategies.

* **[Yulu Micro-Mobility Hypothesis Testing](./YuluHypothesisTesting)**
  * **Focus:** 2-Sample T-tests, ANOVA, Chi-Square Tests of Independence.
  * **Description:** A robust statistical evaluation of the variables impacting shared electric cycle demand, rigorously testing the significance of working days, seasons, and weather conditions.

* **[Walmart Statistical Analysis](./walmart-analysis)**
  * **Focus:** Central Limit Theorem (CLT), Confidence Intervals, Standard Error.
  * **Description:** An application of fundamental inferential statistics to estimate population spending parameters from sample data, establishing confidence bounds for retail revenue forecasting.

*Note: Each project folder contains a dedicated README detailing the specific business problem, methodology, and actionable recommendations, alongside the respective Jupyter Notebooks and datasets.*
